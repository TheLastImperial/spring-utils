# Utils module

Utils to Spring Boot project.

## Javadoc

To look all the documentation you can generate it with JavaDoc.

```bash
mvn javadoc:javadoc
```

## Views components.

Fragment pagination.

Parameters:

- page: The current page number.
- defaultSize: A default value of the page size.
- baseUrl: The base URL to do requests.
- txtPage: Text `page`
- txtOf: Text `of`
- txtPrevius: Text `Previus`
- txtNext: Text `Next`
